# LLM 관련 테이블

원격 Supabase에 이미 생성된 스키마다. (PascalCase 식별자, quoted `"TableName"`)

관계 개요:

```
LLMProvider (1) ──< LLMUserPermission (N)  사용자×제공자 승인·할당 토큰
                ├──< LLMUserQuota (N)      사용자×제공자×월 누적
                ├──< LLMTokenHistory (N)   호출 단위 이력
                └──< ChatSession (N)       대화 세션 → ChatMessage (N)
                                           (상세: chat.md)
```

`SerialNo`는 사용자 일련번호다. 기존 `nrm_user_list.serial_no`는 **text**, 본 LLM 테이블은 **bigint** 이므로 연동 시 형 변환·값 규칙을 맞출 것.

## LLMProvider

LLM 제공자 및 모델 정보.

| 컬럼 | 타입 | 기본값 | NULL | 설명 |
|------|------|--------|------|------|
| `ProviderID` | `bigint` IDENTITY PK | — | NO | LLM 제공자 고유번호 |
| `ProviderName` | `varchar` | — | NO | 제공자명 (Gemini, OpenAI, Claude 등) |
| `ModelName` | `varchar` | — | NO | 모델명 (예: `gemini-2.5-flash`) |
| `ApiKey` | `text` | — | NO | LLM API Key |
| `IsActive` | `boolean` | `true` | NO | 사용 여부 |
| `DailyLimit` | `bigint` | `0` | NO | 일일 토큰 제한 (`0` = 제한 없음) |
| `MonthlyLimit` | `bigint` | `0` | NO | 월간 토큰 제한 (`0` = 제한 없음) |
| `RegDate` | `timestamptz` | `now()` | NO | 등록일시 |

### DDL

```sql
CREATE TABLE public."LLMProvider"
(
    "ProviderID"    bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    "ProviderName"  varchar NOT NULL,
    "ModelName"     varchar NOT NULL,
    "ApiKey"        text NOT NULL,
    "IsActive"      boolean NOT NULL DEFAULT true,
    "DailyLimit"    bigint NOT NULL DEFAULT 0,
    "MonthlyLimit"  bigint NOT NULL DEFAULT 0,
    "RegDate"       timestamptz NOT NULL DEFAULT now()
);

COMMENT ON TABLE public."LLMProvider"
IS 'LLM 제공자 및 모델 정보';

COMMENT ON COLUMN public."LLMProvider"."ProviderID"
IS 'LLM 제공자 고유번호';

COMMENT ON COLUMN public."LLMProvider"."ProviderName"
IS 'LLM 제공자명 (Gemini, OpenAI, Claude 등)';

COMMENT ON COLUMN public."LLMProvider"."ModelName"
IS '사용할 모델명 (gemini-2.5-flash 등)';

COMMENT ON COLUMN public."LLMProvider"."ApiKey"
IS 'LLM API Key';

COMMENT ON COLUMN public."LLMProvider"."IsActive"
IS '사용 여부';

COMMENT ON COLUMN public."LLMProvider"."DailyLimit"
IS '일일 토큰 제한 (0은 제한 없음)';

COMMENT ON COLUMN public."LLMProvider"."MonthlyLimit"
IS '월간 토큰 제한 (0은 제한 없음)';

COMMENT ON COLUMN public."LLMProvider"."RegDate"
IS '등록일시';
```

## LLMUserQuota

사용자 월별 LLM 토큰 사용량 (누적).

| 컬럼 | 타입 | 기본값 | NULL | 설명 |
|------|------|--------|------|------|
| `QuotaID` | `bigint` IDENTITY PK | — | NO | 사용량 고유번호 |
| `SerialNo` | `bigint` | — | NO | 사용자 일련번호 |
| `ProviderID` | `bigint` | — | NO | LLM 제공자 고유번호 (`LLMProvider.ProviderID`) |
| `TargetMonth` | `varchar(6)` | — | NO | 사용월 (`YYYYMM`) |
| `InputToken` | `bigint` | `0` | NO | 누적 입력 토큰 (LLM에 보낸 토큰 수) |
| `OutputToken` | `bigint` | `0` | NO | 누적 출력 토큰 (LLM이 생성한 토큰 수) |
| `TotalToken` | `bigint` | `0` | NO | 누적 전체 토큰 (`InputToken + OutputToken`) |
| `RegDate` | `timestamptz` | `now()` | NO | 생성일시 |
| `UpdateDate` | `timestamptz` | `now()` | NO | 최종 수정일시 |

### 제약·인덱스

- **UNIQUE** `UX_LLMUserQuota` (`SerialNo`, `ProviderID`, `TargetMonth`)  
  → 동일 사용자·동일 제공자·동일 월은 **1건만** 존재.

### DDL

```sql

    "InputToken"    bigint NOT NULL DEFAULT 0,
    "OutputToken"   bigint NOT NULL DEFAULT 0,
    "TotalToken"    bigint NOT NULL DEFAULT 0,

    "UpdateDate"    timestamptz NOT NULL DEFAULT now()

IS '사용량 고유번호';

IS '사용자 일련번호';

COMMENT ON COLUMN public."LLMUserQuota"."ProviderID"
IS 'LLM 제공자 고유번호';

COMMENT ON COLUMN public."LLMUserQuota"."TargetMonth"
IS '사용월 (YYYYMM)';

COMMENT ON COLUMN public."LLMUserQuota"."InputToken"
IS '누적 입력 토큰(LLM에게 보낸 토큰 수)';

COMMENT ON COLUMN public."LLMUserQuota"."OutputToken"
IS '누적 출력 토큰(LLM이 생성한 토큰 수)';

COMMENT ON COLUMN public."LLMUserQuota"."TotalToken"
IS '누적 전체 토큰(InputToken + OutputToken)';
```

## 구현 시 참고

- `ApiKey`는 클라이언트(APK)에 노출하지 않는 경로로만 사용한다. (Edge Function / 백엔드 / service_role 등)
- 호출 전: `LLMUserPermission`에서 `IsApproved`·`AllocatedToken`을 확인한다.
- 호출 후: `LLMTokenHistory` INSERT + 해당 월 `LLMUserQuota` upsert(누적)를 함께 갱신하는 흐름을 권장.
- `DailyLimit` / `MonthlyLimit`는 **제공자** 단위 제한, `AllocatedToken`은 **사용자×제공자** 할당 한도다.
- 대화 세션·메시지는 [`chat.md`](./chat.md) (`ChatSession`, `ChatMessage`).
- FK(`ProviderID` → `LLMProvider`)는 현재 DDL에 없음. 필요 시 마이그레이션으로 추가 가능.
