# Chat 관련 테이블

원격 Supabase에 이미 생성된 스키마다. (PascalCase 식별자, quoted `"TableName"`)

관계 개요:

```
LLMProvider (1) ──< LLMModel (N)
                └──< ChatSession (N) ──< ChatMessage (N)
                     (ChatSession은 ProviderID + ModelID를 함께 저장 — 세션 고정 모델)
                         │
                    SerialNo (사용자)
```

권한·토큰 누적은 [`llm.md`](./llm.md) (`LLMUserPermission`, `LLMUserQuota`, `LLMTokenHistory`) 참고.

`SerialNo`는 **varchar**. 기존 `nrm_user_list.serial_no`(**text**)·앱 `getNrmAppSerialNo()` 값(예: `"admin"`, 숫자 문자열)을 그대로 저장한다. (과거 `bigint`였던 것을 `varchar`로 변경 — 형 변환 없이 원문 그대로 저장)

---

## ChatSession

사용자별 LLM 대화 세션. AI Lab 좌측 대화 목록에 대응.

| 컬럼 | 타입 | 기본값 | NULL | 설명 |
|------|------|--------|------|------|
| `SessionID` | `bigint` IDENTITY | — | NO | 대화 세션 고유번호 **(복합 PK)** |
| `SerialNo` | `varchar` | — | NO | 사용자 일련번호 (앱 `getNrmAppSerialNo()` 원문, 예: `"admin"`, `"1092452918"`) **(복합 PK)** |
| `ProviderID` | `bigint` | — | NO | LLM 제공자 고유번호 (`LLMProvider.ProviderID`) |
| `ModelID` | `bigint` | — | NO | 이 세션이 마지막으로 사용한 LLM 모델 (`LLMModel.ModelID`). 생성 시 넣고, 클라이언트가 모델을 바꾸면 `nrm_rpc_chat_prepare_turn`이 갱신 |
| `Title` | `varchar` | — | NO | 대화 제목 |
| `IsDeleted` | `boolean` | `false` | NO | 삭제 여부 (소프트 삭제) |
| `RegDate` | `timestamptz` | `now()` | NO | 생성 일시 |
| `UpdateDate` | `timestamptz` | `now()` | NO | 마지막 대화 일시 |

### PK·인덱스

- **PK** `PK_ChatSession` (`SessionID`, `SerialNo`)
- `IX_ChatSession_SerialNo` (`SerialNo`) — `SerialNo` 단독 조회용 (복합 PK 2번째 컬럼이라 별도 인덱스 유지)
- `IX_ChatSession_UpdateDate` (`UpdateDate` DESC)

### DDL

```sql
CREATE TABLE public."ChatSession"
(
    "SessionID"     bigint GENERATED BY DEFAULT AS IDENTITY NOT NULL,
    "SerialNo"      varchar NOT NULL,
    "ProviderID"    bigint NOT NULL,
    "Title"         varchar NOT NULL,
    "IsDeleted"     boolean NOT NULL DEFAULT false,
    "RegDate"       timestamptz NOT NULL DEFAULT now(),
    "UpdateDate"    timestamptz NOT NULL DEFAULT now(),
    CONSTRAINT "PK_ChatSession" PRIMARY KEY ("SessionID", "SerialNo")
);

COMMENT ON TABLE public."ChatSession"
IS '사용자별 LLM 대화 세션';

COMMENT ON COLUMN public."ChatSession"."SessionID"
IS '대화 세션 고유번호';

COMMENT ON COLUMN public."ChatSession"."SerialNo"
IS '사용자 일련번호 (앱 SerialNo 원문, 예: admin, 1092452918)';

COMMENT ON COLUMN public."ChatSession"."ProviderID"
IS 'LLM 제공자 고유번호 (LLMProvider.ProviderID)';

COMMENT ON COLUMN public."ChatSession"."ModelID"
IS '이 세션이 사용하는 LLM 모델 고유번호 (LLMModel.ModelID) — 세션 생성 시 고정';

COMMENT ON COLUMN public."ChatSession"."Title"
IS '대화 제목';

COMMENT ON COLUMN public."ChatSession"."IsDeleted"
IS '삭제 여부';

COMMENT ON COLUMN public."ChatSession"."RegDate"
IS '생성 일시';

COMMENT ON COLUMN public."ChatSession"."UpdateDate"
IS '마지막 대화 일시';

CREATE INDEX "IX_ChatSession_SerialNo"
ON public."ChatSession" ("SerialNo");

CREATE INDEX "IX_ChatSession_UpdateDate"
ON public."ChatSession" ("UpdateDate" DESC);
```

## ChatMessage

LLM 대화 메시지. 세션 내 말풍선에 대응.

| 컬럼 | 타입 | 기본값 | NULL | 설명 |
|------|------|--------|------|------|
| `MessageID` | `bigint` IDENTITY | — | NO | 메시지 고유번호 **(복합 PK)** |
| `SessionID` | `bigint` | — | NO | 대화 세션 고유번호 (`ChatSession.SessionID`) **(복합 PK)** |
| `Role` | `varchar` | — | NO | 메시지 작성자 (사용자`SerialNo`, `assistant`, `system`) |
| `Content` | `text` | — | NO | 메시지 내용 |
| `InputToken` | `integer` | `0` | NO | 이번 요청의 입력 토큰 |
| `OutputToken` | `integer` | `0` | NO | 이번 응답의 출력 토큰 |
| `TotalToken` | `integer` | `0` | NO | 이번 요청의 총 토큰 |
| `RegDate` | `timestamptz` | `now()` | NO | 메시지 생성 일시 |
| `UiMeta` | `jsonb` | — | YES | AI Lab UI 복원 메타. `choices` / `agentUi` / `youtubeConfirm`(미리듣기 세션 스냅샷). NULL이면 텍스트만 |

### PK·인덱스

- **PK** `PK_ChatMessage` (`MessageID`, `SessionID`)
- `IX_ChatMessage_SessionID` (`SessionID`) — 세션별 메시지 조회용 (복합 PK 2번째 컬럼이라 별도 인덱스 유지)
- `IX_ChatMessage_RegDate` (`RegDate`)

### DDL

```sql
CREATE TABLE public."ChatMessage"
(
    "MessageID"      bigint GENERATED BY DEFAULT AS IDENTITY NOT NULL,
    "SessionID"      bigint NOT NULL,

    "InputToken"     integer NOT NULL DEFAULT 0,
    "OutputToken"    integer NOT NULL DEFAULT 0,

COMMENT ON COLUMN public."ChatMessage"."MessageID"
IS '메시지 고유번호';

COMMENT ON COLUMN public."ChatMessage"."SessionID"
IS '대화 세션 고유번호';

COMMENT ON COLUMN public."ChatMessage"."Role"
IS '메시지 작성자 (사용자SerialNo, assistant, system)';

COMMENT ON COLUMN public."ChatMessage"."Content"
IS '메시지 내용';

COMMENT ON COLUMN public."ChatMessage"."InputToken"
IS '이번 요청의 입력 토큰';

COMMENT ON COLUMN public."ChatMessage"."OutputToken"
IS '이번 응답의 출력 토큰';

COMMENT ON COLUMN public."ChatMessage"."TotalToken"
IS '이번 요청의 총 토큰';

COMMENT ON COLUMN public."ChatMessage"."RegDate"
IS '메시지 생성 일시';

COMMENT ON COLUMN public."ChatMessage"."UiMeta"
IS 'AI Lab UI 복원 메타(choices/agentUi/youtubeConfirm 스냅샷). NULL이면 텍스트만';

CREATE INDEX "IX_ChatMessage_SessionID"
ON public."ChatMessage" ("SessionID");
```

## 보안·쓰기 경로

- `ChatSession`/`ChatMessage`는 RLS `SELECT`만 anon/authenticated에 열려 있다(`20260721120000_llm_chat_security_harden.sql`). **직접 INSERT/UPDATE 불가.**
- 메시지 저장·세션 생성·`UpdateDate` 갱신은 전부 Edge Function(`llm-chat-send`, service_role)이 `nrm_rpc_chat_prepare_turn`/`nrm_rpc_chat_finalize_turn`을 통해서만 수행한다. 상세: [`llm.md`](./llm.md#ai-lab-채팅-전송--edge-function--rpc-실제-구현).
- 칩·YouTube 미리듣기·로컬 말풍선 UI 메타는 앱이 `nrm_rpc_chat_append_ui_messages` / `nrm_rpc_chat_patch_message_ui_meta`로 `ChatMessage.UiMeta`에 저장한다(anon/authenticated GRANT, 본인 세션만). 마이그레이션: `20260731170000_chat_message_ui_meta.sql`.
- `UiMeta.youtubeConfirm`는 미리듣기 후보 스냅샷(videoId·메타, **스트림 URL·가사 전문 제외**). 세션 재진입 시 hydrate 후 스트림만 재발급한다. 칩만 지울 때는 youtubeConfirm를 유지하고, 「맞다/아니다」후에만 제거한다.
- Edge `llm-chat-send` finalize로 저장된 assistant 행에도 앱이 `nrm_rpc_chat_patch_message_ui_meta`로 `youtubeConfirm`를 붙인다(로컬 append만 하면 finalize 행은 텍스트만 남아 재진입 시 플레이어가 사라짐).
- 앱은 세션 생성 시 persist 스냅샷을 캐시해, ChatMessage 저장 시 메모리 세션 조회 실패로 UiMeta가 빠지지 않게 한다.
- `ChatSession.Title` 갱신(휴리스틱 임시 제목 → LLM 요약 제목)도 `nrm_rpc_chat_update_session_title`(service_role 전용)로만 가능하다. 상세: [`llm.md`](./llm.md#대화-제목-llm-요약-2026-07-29-복구).
- 세션 삭제(소프트 삭제, `IsDeleted=true`)는 앱이 `nrm_rpc_chat_delete_session(p_serial_no, p_session_id)`을 직접 호출한다(anon/authenticated에 GRANT). 본인 `SerialNo` 소유 세션만 삭제 가능.

## 구현 시 참고

- 목록: `ChatSession`에서 `IsDeleted = false`만, `UpdateDate DESC` 정렬(`IX_ChatSession_UpdateDate`). 앱: `app/lib/nrmChatClient.ts#fetchChatSessions`.
- 세션 진입 시 메시지 지연 로딩(`fetchChatMessages`) — 목록 단계에서는 메시지를 가져오지 않아 목록 조회가 가볍다.
- 새 메시지 후: `ChatMessage` INSERT + 해당 `ChatSession.UpdateDate` 갱신(RPC 안에서 원자적으로 처리).
- 대화 히스토리를 LLM에 다시 보낼 때는 `Role = 'system'`인 행을 제외한다(우리 쪽 안내 메시지일 뿐 실제 대화 turn이 아님). 최근 40건으로 캡.
- 토큰은 메시지 단위로 `ChatMessage`에 기록하고, 누적·한도는 `LLMUserQuota` / `LLMUserPermission` / `LLMTokenHistory`와 함께 맞춘다.
- **복합 PK**: `ChatSession` (`SessionID`, `SerialNo`), `ChatMessage` (`MessageID`, `SessionID`). PostgREST upsert·앱 코드에서 `onConflict` 대상 컬럼을 복합 PK에 맞출 것.
- FK(`SessionID` → `ChatSession`, `ProviderID` → `LLMProvider`)는 현재 DDL에 없음. 필요 시 마이그레이션으로 추가 가능.
