# App Navigation Rules

NullReferenceMusic 모바일 UX 일관성을 위한 내비게이션 규칙.

## 1) 로고 탭 동작

- 상단 `Nullreference Music` 로고를 탭하면 항상 앱 초기 홈 화면으로 복귀한다.
- 초기 홈 상태는 "검색 결과 없음 + 재생 선택 없음 + 검색 흐름 초기화"를 의미한다.

## 2) 검색 요청 경쟁 제어

- 사용자는 검색 결과 렌더링 중에도 검색어를 수정하고 재검색할 수 있어야 한다.
- 최신 검색 요청만 유효하며, 이전 요청의 응답은 도착하더라도 폐기한다.
- 검색 UX는 "blocking"이 아니라 "latest-wins" 정책을 따른다.

## 3) Android 하드웨어 뒤로가기

- 검색/탐색 상태(`browsing`)에서 뒤로가기 버튼을 누르면 직전 검색 상태로 가지 않고
  즉시 앱 초기 홈 화면으로 복귀한다.
- 초기 홈 화면(`welcome`)에서 뒤로가기는 OS 기본 동작(앱 종료/백스택 처리)을 따른다.

## 4) 기능 확장 시 준수 사항

- 검색/탭/플레이어/다운로드 등 새 기능이 추가되어도 "홈 복귀 규칙"은 최우선으로 유지한다.
- 새로운 상태를 추가할 때는 반드시 다음 두 질문을 통과해야 한다.
  - 로고 탭 시 해당 상태는 초기화되는가?
  - Android 뒤로가기 시 홈 복귀 규칙을 깨지 않는가?
