# 기간별 차트 드롭다운 스크롤바 디자인

## 목적

웹에서 기간별 필터 드롭다운의 스크롤바가 테마와 어울리지 않고 튀어 보이던 문제를 줄이고, 모바일/웹의 사용 경험을 통일한다.

## 적용 범위

- 컴포넌트: `app/components/nrm/charts/NrmPeriodChartDropdown.tsx`
- 대상 화면:
  - Spotify 기간별 차트 필터
  - Last.fm 기간별 차트 필터

## 디자인 원칙

- 웹/모바일 모두 같은 상호작용(트리거 버튼 -> 모달 리스트)을 사용한다.
- 다크/라이트 테마 각각에 맞는 대비를 유지한다.
- 스크롤 영역은 콘텐츠보다 과하게 튀지 않도록 `thin` 계열 톤으로 맞춘다.

## 상세 사양

### 1) 공통 드롭다운 구조

- 트리거: 기존 필터 박스 스타일 유지 (`40px` 높이)
- 리스트: `Modal` 내부 `ScrollView` 사용
- 항목: 행 단위 선택 + 선택값 체크 아이콘 표시

### 2) 테마별 톤

- 다크:
  - 배경: `surfaceTile1`
  - 경계선: `borderOnDark`
  - 스크롤바: 밝은 회색 thumb + 어두운 트랙
- 라이트:
  - 배경: `canvas`
  - 경계선: `hairline`
  - 스크롤바: 중간 회색 thumb + 옅은 트랙

### 3) 스크롤바 스타일(웹)

- `colorScheme`: 다크/라이트 자동 전환
- `scrollbarWidth: thin`
- `scrollbarColor`: 테마별 thumb/track 색상 지정

브라우저별 구현 차이는 존재할 수 있으나, 기본 목표는 "고대비 튐"을 줄이고 필터 UI와 톤을 맞추는 것이다.

### 4) 가독성 보정

- 옵션 행 하단에 hairline 구분선 추가
- 선택 행은 primary 기반 약한 배경 강조
